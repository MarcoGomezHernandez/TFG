
En las siguientes secciones se listan los accesos a los repositorios de control de versiones correspondientes al código fuente desarrollado y a las librerías de terceros empleadas en el proyecto.


\section{Repositorio de Parametrización Sináptica (BO)\label{SEC:PARAMETRIZACIONREPO}}

En este repositorio se almacena el código completo del presente Trabajo. Abarca la variante \textit{offline} elaborada en C++ con gestión de sub-stepping temporal y arquitectura modular mediante \textit{Templates}, así como la implementación orientada a RTXI (\textit{online}) con los mecanismos de \textit{Double-Buffering} atómicos \textit{lock-free} expuestos en el Capítulo~\ref{CAP:DISEÑOYDESARROLLO}.

Se puede acceder a todo el material a través de \MYhref{https://github.com/Pablosanmar97/Parametrization_chemical}{este enlace}.


\section{Framework Computacional Neuronal (Neun)\label{SEC:NEUNREPO}}

Colección que estructura el comportamiento de los modelos neuronales subyacentes, agrupando las integraciones abstractas utilizadas por la simulación (tales como las modificaciones del modelo de Hindmarsh-Rose de tres dimensiones).

Se puede acceder a través de \MYhref{https://github.com/GNB-UAM/Neun}{este enlace}.


\section{Ecosistema RTHybrid\label{SEC:RTHYBRIDREPO}}

Conjunto de software abierto liderado por el Grupo de Neurocomputación Biológica (GNB) de la Universidad Autónoma de Madrid. Aporta las rutinas algorítmicas troncales para escalar dinámicas entre sustratos \textit{in silico} y orgánicos, operando como base de partida para las modificaciones asíncronas de Optimización Bayesiana \cite{Amaducci2019}.

Se puede acceder a través de \MYhref{https://github.com/gnb-uam/rthybrid}{este enlace}.


\section{RTXI Plugins (GNB-UAM)\label{SEC:RTXIPLUGINSGNB}}

Repositorio que hospeda los módulos base de \textit{Dynamic Clamp} diseñados por el GNB para RTXI 2.3. Proporciona la infraestructura de plugins y las ejecuciones nativas en entornos con \textit{Xenomai} \cite{Xenomai2024}. El módulo \texttt{bidirectional\_chemical\_synapse\_BO} desarrollado en este Trabajo no se incluye en este repositorio, sino en el repositorio de Parametrización Sináptica (Apéndice~\ref{SEC:PARAMETRIZACIONREPO}).

Se puede acceder a través de \MYhref{https://github.com/GNB-UAM/rthybrid-for-rtxi}{este enlace}.


\section{Librerías de Terceros\label{SEC:TERCEROS}}


\subsection{Limbo (LIbrary for Model-Based Optimization)\label{SUBSEC:LIMBOREPO}}

Librería C++11 dedicada a la Optimización Bayesiana mediante Procesos Gaussianos y funciones de adquisición \textit{Expected Improvement}. Es el motor principal de la búsqueda paramétrica en la configuración asíncrona del hilo NRT \cite{Cully2018}.

Se puede acceder a través de \MYhref{https://github.com/resibots/limbo}{este enlace}.


\subsection{KFR (C++ DSP Framework)\label{SUBSEC:KFRREPO}}

Biblioteca C++ de Procesamiento Digital de Señales (DSP) optimizada para instrucciones SIMD (AVX2). Implementa los filtros Butterworth paso bajo de cuarto orden que aíslan las envolventes morfológicas ($I_{fast}$, $I_{slow}$) de los trenes de potenciales \cite{KFRLib2023}.

Se puede acceder a través de \MYhref{https://github.com/kfrlib/kfr}{este enlace}.

\section{Módulo Mimic Signal para RTXI\label{SEC:MIMICSIGNALREPO}}

Repositorio que almacena el código fuente del plugin \texttt{mimic-signal} diseñado para el entorno RTXI. Este módulo de procesamiento en tiempo real copia una señal de entrada (\textit{Vin}) y emite una señal de salida (\textit{Vout}) aplicando un multiplicador escalar de ganancia (\textit{Gain}) y un nivel de desplazamiento continuo (\textit{Offset}) definidos por el usuario. La arquitectura está desarrollada en C++ e integra las bibliotecas Qt5 para la gestión de su interfaz gráfica de usuario.

Se puede acceder a todo el material a través de \MYhref{https://github.com/RTXI/mimic-signal}{este enlace}
