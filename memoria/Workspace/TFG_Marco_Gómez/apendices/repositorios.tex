
En las siguientes secciones se listan los accesos a los repositorios correspondientes al código fuente desarrollado y a las librerías de terceros empleadas en el proyecto.


\section{Repositorio con el código desarrollado\label{SEC:PROPIOS}}

En esta sección se listan los repositorios que contienen el código desarrollado específicamente para este proyecto.


\section{Repositorios de terceros\label{SEC:TERCEROS}}

\section{Librería computacional neuronal (Neun)\label{SEC:NEUNREPO}}

Colección que estructura el comportamiento de los modelos neuronales subyacentes, agrupando las integraciones abstractas utilizadas por la simulación (tales como las modificaciones del modelo de \ac{hr} de tres dimensiones).

Se puede acceder a través de \MYhref{https://github.com/GNB-UAM/Neun}{este enlace}.


\section{Ecosistema \acs{rthybrid}\label{SEC:RTHYBRIDREPO}}

Conjunto de software abierto liderado por el \ac{gnb} de la \ac{uam}. Aporta las rutinas algorítmicas troncales para escalar dinámicas entre sustratos \textit{in silico} y orgánicos, operando como base de partida para las modificaciones asíncronas de \ac{bo} \cite{Amaducci2019}.

Se puede acceder a través de \MYhref{https://github.com/gnb-uam/rthybrid}{este enlace}.


\section{\acs{rtxi} plugins (\acs{gnb}-\acs{uam})\label{SEC:RTXIPLUGINSGNB}}

Repositorio que hospeda los módulos base de \textit{Dynamic Clamp} diseñados por el \ac{gnb} para \ac{rtxi} 2.3. Proporciona la infraestructura de plugins y las ejecuciones nativas en entornos con \textit{Xenomai} \cite{Xenomai2024}. El módulo \texttt{bidirectional\_chemical\_synapse\_BO} desarrollado en este Trabajo no se incluye en este repositorio, sino en el repositorio de Parametrización Sináptica (Apéndice~\ref{SEC:PARAMETRIZACIONREPO}).

Se puede acceder a través de \MYhref{https://github.com/GNB-UAM/rthybrid-for-rtxi}{este enlace}.


\subsection{Limbo (Library for Model-Based Optimization)\label{SUBSEC:LIMBOREPO}}

Librería C++11 dedicada a la \ac{bo} mediante Procesos Gaussianos y funciones de adquisición \textit{Expected Improvement}. Es el motor principal de la búsqueda paramétrica en la configuración asíncrona del hilo \ac{nrt} \cite{Cully2018}.

Se puede acceder a través de \MYhref{https://github.com/resibots/limbo}{este enlace}.


\subsection{KFR (C++ DSP Framework)\label{SUBSEC:KFRREPO}}

Biblioteca C++ de Procesamiento Digital de Señales (DSP) optimizada para instrucciones SIMD (AVX2). Implementa los filtros Butterworth paso bajo de cuarto orden que aíslan las envolventes morfológicas ($I_{fast}$, $I_{slow}$) de los trenes de potenciales \cite{KFRLib2023}.

Se puede acceder a través de \MYhref{https://github.com/kfrlib/kfr}{este enlace}.

\section{Módulo Mimic Signal para \acs{rtxi}\label{SEC:MIMICSIGNALREPO}}

Repositorio que almacena el código fuente del plugin \texttt{mimic-signal} diseñado para el entorno \ac{rtxi}. Este módulo de procesamiento en \ac{rt} copia una señal de entrada (\textit{Vin}) y emite una señal de salida (\textit{Vout}) aplicando un multiplicador escalar de ganancia (\textit{Gain}) y un nivel de desplazamiento continuo (\textit{Offset}) definidos por el usuario. La arquitectura está desarrollada en C++ e integra las bibliotecas Qt5 para la gestión de su interfaz gráfica de usuario.

Se puede acceder a todo el material a través de \MYhref{https://github.com/RTXI/mimic-signal}{este enlace}


\section{Plantilla de módulo \acs{rtxi} 2.3\label{SEC:PLUGINTEMPLATEREPO}}

Plantilla oficial de módulo para \ac{rtxi} versión 2.3, utilizada como base para el desarrollo del módulo \texttt{bidirectional\_chemical\_synapse\_BO} de este trabajo \cite{RTXIPluginTemplate}. Proporciona la estructura de ficheros, el sistema de compilación y los \textit{callbacks} necesarios para la integración con el hilo de \ac{rt} de \ac{rtxi}.

Se puede acceder a través de \MYhref{https://github.com/RTXI/plugin-template}{este enlace}.
